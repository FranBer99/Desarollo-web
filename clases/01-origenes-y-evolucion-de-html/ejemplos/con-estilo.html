Bienvenidos a la web

Este documento reproduce el espíritu de las primeras páginas publicadas en el CERN: texto, listas y enlaces. La diferencia es que ahora una hoja de estilos define la tipografía, el color y el ancho de lectura.

Qué se puede publicar

  • Documentos de texto con títulos y párrafos.
  • Listas de elementos.
  • Enlaces a otras páginas.
  • Imágenes, cuando el navegador las soporta.
