Historia de la web

Del texto plano a la web

Cómo el hipertexto convirtió documentos aislados en una red de conocimiento y por qué la tipografía sigue siendo una decisión de diseño, no un accidente.

Publicado el 28 de octubre de 2026 · Lectura de 4 minutos

Un documento, muchos destinos

En 1991, el primer sitio web del mundo era apenas una página de texto con enlaces. No tenía tipografías personalizadas ni animaciones: tenía información conectada. Esa idea —el hipertexto— sigue siendo el corazón de la web.

El navegador se encarga de interpretar el marcado y aplicar sus estilos por defecto. Nosotros podemos cambiarlos con CSS, pero el significado del contenido no depende de la apariencia.

La web es más grande que cualquier empresa.

— Tim Berners-Lee

Tres decisiones que mejoran la lectura

La legibilidad no es cuestión de gustos: hay medidas que se pueden comprobar.

  1. Ancho de línea. Entre 45 y 75 caracteres por línea; se logra con max-width: 65ch.
  2. Altura de línea. Un valor entre 1.5 y 1.8 para texto corrido.
  3. Contraste. Al menos 4.5:1 para texto normal, según WCAG.

Un ejemplo mínimo

Estas reglas alcanzan para que un artículo se lea bien:

body {
  max-width: 65ch;
  margin-inline: auto;
  font-family: system-ui, sans-serif;
  line-height: 1.7;
}

Lo que no cambia

Las modas tipográficas van y vienen, pero la estructura semántica permanece: un h1 sigue siendo el título principal, una lista sigue siendo una lista y una cita sigue siendo una cita. Esa es la parte que conviene cuidar.
