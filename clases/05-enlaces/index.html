Clase 05

Enlaces e hipervínculos

Los enlaces son lo que convierte documentos sueltos en una web. Esta clase cubre cómo se construye una URL, qué tipos de enlaces existen y cómo escribirlos para que sean claros, seguros y accesibles.

Objetivos
  • Comprender el concepto de navegación y de hipertexto.
  • Identificar las partes de una URL y distinguir rutas absolutas y relativas.
  • Crear enlaces internos, externos, anclas y enlaces de descarga.
  • Usar target, rel y download con criterio.
  • Escribir enlaces accesibles y seguros.

¿Qué es un enlace?

Un enlace es una referencia de un documento a otro recurso: otra página, una sección dentro de la misma página, un archivo, una dirección de correo o un número de teléfono. En HTML se crea con el elemento <a> (anchor) y el atributo href (hypertext reference).

El contenido del enlace es lo que se ve y se clickea. Puede ser texto, una imagen o ambos, pero debe describir el destino. El atributo href es obligatorio: sin él, el elemento no es un enlace.

Enlace o botón

Un enlace navega a otro recurso. Un botón ejecuta una acción: enviar un formulario, abrir un menú, reproducir un video. No uses un <a> con href="#" para simular un botón, ni un <div> con un clic para simular un enlace: rompen el teclado y los lectores de pantalla.

La web se puede pensar como un grafo: cada página es un nodo y cada enlace una arista. Esa estructura es la que permite pasar de un documento a otro sin conocer de antemano dónde está la información.

Anatomía de una URL

Una URL (Uniform Resource Locator) es la dirección de un recurso. No es lo mismo que un URI (identificador) ni que un dominio (el nombre del servidor): la URL incluye todo lo necesario para localizar el recurso.

Componentes de una URL
Parte Ejemplo Qué indica
Esquemahttps:Protocolo de acceso: HTTP seguro, correo, teléfono, archivo.
Hostwww.ejemplo.edu.arNombre del servidor.
Puerto:443Puerto de red; se omite si es el predeterminado del esquema.
Ruta/carreras/sistemasUbicación del recurso dentro del servidor.
Consulta?plan=2023Parámetros para el servidor o la aplicación.
Fragmento#horariosParte del documento a la que se salta; no se envía al servidor.

Rutas absolutas y relativas

Tipos de rutas en href
Tipo Ejemplo Uso
Absoluta https://ejemplo.edu.ar/cursos/ Destino completo. Necesaria para otros sitios.
Relativa al documento ../contacto.html Dentro del mismo sitio; depende de la ubicación actual.
Relativa a la raíz /cursos/contacto.html Desde la raíz del dominio.
Ancla #horarios Un elemento con id="horarios" en la misma página.
Otros esquemas mailto:, tel: Abrir el cliente de correo o el teléfono.

Las rutas relativas hacen que el sitio funcione igual en local, en un subdirectorio o en un dominio propio. Por ejemplo, este material usa rutas relativas para poder publicarse en GitHub Pages sin cambios.

Caracteres reservados

Los espacios y muchos caracteres especiales deben codificarse en la URL: un espacio se escribe %20 y la ñ, %C3%B1. En la práctica, conviene usar nombres de archivo en minúsculas, sin espacios y sin tildes: horarios-2026.html en lugar de Horarios 2026.html.

Anclas

Un ancla es un enlace a un id dentro del documento. El destino debe tener ese identificador, que es único y distingue mayúsculas de minúsculas. Es la base de los índices de contenidos, los “volver arriba” y la navegación dentro de una página larga.

Cuando el encabezado queda tapado por una barra fija, se corrige con scroll-margin-top en el elemento destino. También se puede resaltar el destino con la pseudoclase :target.

Tipos de enlaces

Internos

Apuntan a otra página o recurso del mismo sitio. Se escriben con rutas relativas y son la estructura de la navegación: menú principal, migas de pan, enlaces entre clases. Si el destino es una carpeta, el servidor devuelve su index.html; conviene ser explícito y escribir la ruta completa del archivo.

Externos

Apuntan a otro dominio. Se escriben con la URL absoluta, incluido https://. Un enlace externo no necesita target="_blank": abrir una pestaña nueva sin avisar desorienta y rompe el botón “atrás”. Si hay una razón para hacerlo, se avisa en el texto o con un ícono acompañado de texto alternativo.

Anclajes

Pueden ser internos (#seccion) o combinar página y fragmento (otra-pagina.html#seccion). Son ideales para índices, preguntas frecuentes y documentación.

Enlaces de acción

  • mailto:contacto@ejemplo.edu.ar abre el cliente de correo.
  • tel:+541112345678 inicia una llamada en dispositivos compatibles.
  • download descarga un archivo en lugar de navegarlo, cuando el navegador lo permite.

Atributos de enlace

Atributos de <a>
Atributo Para qué sirve Valores habituales
href Destino del enlace. Es obligatorio. URL, ruta relativa o fragmento.
target Dónde se abre el destino. _self (predeterminado), _blank, _parent, _top.
rel Relación entre el documento actual y el destino. noopener, noreferrer, nofollow.
download Sugiere descargar el recurso en lugar de abrirlo. Vacío o un nombre de archivo.
hreflang Idioma del recurso enlazado. es, en, pt-BR.
type Tipo MIME del recurso. application/pdf, text/html.
title Información adicional. No reemplaza al texto del enlace. Texto breve.

target

_self abre en la misma pestaña y es el comportamiento predeterminado. _blank abre en una pestaña nueva. _parent y _top solo tienen sentido dentro de marcos (clase 8). No se usan nombres arbitrarios de ventana: están asociados a la navegación con marcos.

rel y seguridad

Cuando un enlace con target="_blank" abre una página externa, esa página podría acceder a la ventana que la abrió. El atributo rel="noopener" corta esa relación; noreferrer además evita enviar la URL de origen. Los navegadores actuales aplican noopener por defecto, pero conviene declararlo para los navegadores antiguos y para que la intención quede explícita.

rel="nofollow" indica a los buscadores que no sigan el enlace. Se usa en comentarios, publicidad o contenido generado por usuarios, no en enlaces propios de confianza.

download

download sugiere descargar el recurso. El navegador solo lo respeta para recursos del mismo origen; si el archivo está en otro dominio, puede abrirlo en su visor. El valor opcional define el nombre sugerido:

En el texto conviene indicar el formato y el tamaño del archivo: quien navega con datos móviles o con un lector de pantalla necesita saber qué va a descargar antes de hacer clic.

Lo que no se hace

  • href="#" para simular una acción: recarga la página y salta al inicio.
  • href="javascript:...": mezcla comportamiento con estructura, bloquea la CSP y es un riesgo de seguridad.
  • href="" o sin href: el elemento no es un enlace navegable.
  • Usar una imagen sin texto alternativo como único contenido del enlace.

Enlaces accesibles

Un enlace tiene que poder usarse con teclado, con lector de pantalla y con el dedo. Estas son las reglas que más impacto tienen:

  • Texto descriptivo. “Ver el cronograma de exámenes” es mejor que “click aquí” o “más información”. Los lectores de pantalla pueden listar todos los enlaces de la página: cada uno debe entenderse fuera de contexto.
  • Foco visible. No elimines el outline sin reemplazarlo por un indicador claro. Este sitio usa :focus-visible.
  • Área clickeable suficiente. WCAG 2.2 recomienda un mínimo de 24 × 24 píxeles. En móviles conviene más.
  • No depender del color. El subrayado ayuda a distinguir un enlace del texto normal, sobre todo para personas con daltonismo.
  • Saltar al contenido. Un enlace al inicio del documento permite evitar el menú y llegar al contenido con el teclado.
  • Página actual. En un menú, marcar el enlace activo con aria-current="page".
Enlaces y botones no son intercambiables

Si el elemento lleva a otra URL, es un enlace y funciona con Enter. Si ejecuta una acción en la página, es un <button> y funciona con Enter y Espacio. Cambiar uno por otro obliga a reimplementar el teclado y el rol semántico.

Actividad práctica

Construir una página de recursos con todos los tipos de enlace y auditar su accesibilidad.

  1. Crear un documento con un índice de tres secciones y enlaces de ancla a cada una.
  2. Agregar un menú de navegación con enlaces internos a otras páginas del ejercicio.
  3. Incluir un enlace externo a la documentación de MDN que se abra en una pestaña nueva, con rel adecuado y aviso en el texto.
  4. Agregar un enlace mailto: y otro tel:.
  5. Ofrecer la descarga de un archivo de texto propio con download e indicar formato y tamaño.
  6. Incluir un enlace “Volver arriba” al final de cada sección.
  7. Recorrer la página solo con Tab: comprobar el orden, el foco visible y que Enter active cada enlace.
  8. Revisar que ningún enlace diga “click aquí” y que todos se entiendan fuera de contexto.

Para entregar: el HTML, el archivo descargable y una lista de comprobación con los ocho puntos anteriores.

Resumen

  • Un enlace es una referencia a otro recurso; se crea con a y href.
  • Una URL combina esquema, host, puerto, ruta, consulta y fragmento.
  • Las rutas relativas hacen que el sitio sea portable; las absolutas se usan para otros dominios.
  • Los enlaces internos, externos, anclas y de acción cubren necesidades distintas.
  • target="_blank" se acompaña de rel="noopener noreferrer" y de un aviso.
  • download sugiere la descarga y conviene informar formato y tamaño.
  • El texto del enlace debe describir el destino; el foco debe ser visible y el área, suficiente.
