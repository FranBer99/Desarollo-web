El modelo de caja

Cada elemento es una caja con cuatro capas. Esta representación exagera los tamaños para que se puedan ver.

Las cuatro capas

margen · 1.5rem
borde · 4px
relleno · 1.5rem
contenido
width: 16rem

El margen real es transparente y no tiene fondo. Acá se dibuja con un borde punteado solo para explicar dónde queda.

content-box y border-box

Las dos cajas tienen el mismo width: 13rem, el mismo relleno y el mismo borde. La diferencia es qué incluye ese ancho.

box-sizing: content-box

contenido

13rem de contenido + 3rem de relleno + 8px de borde: la caja ocupa más de 16rem.

box-sizing: border-box

contenido

El ancho total es 13rem: el relleno y el borde se descuentan del contenido.

Por qué se usa border-box

Con border-box, agregar relleno o borde no cambia el ancho total de la caja. Eso hace que los diseños sean predecibles y que una grilla no se rompa al ajustar el espaciado. Por eso la mayoría de los proyectos aplican: 

*,
*::before,
*::after {
  box-sizing: border-box;
}
