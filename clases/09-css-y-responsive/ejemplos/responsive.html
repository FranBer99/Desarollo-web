Tipografía fluida

Un título que crece con la pantalla

El tamaño usa clamp() para moverse entre un mínimo y un máximo sin saltos bruscos. El ancho de lectura se limita a 65ch para que las líneas no se vuelvan incómodas en pantallas grandes.

Los puntos de corte se eligen mirando el contenido, no los dispositivos. Si el texto se corta o las tarjetas quedan muy angostas, ese es el momento de agregar una media query.
