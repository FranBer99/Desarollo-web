# Programa de la materia

En esta carpeta se conserva el programa analítico de **Desarrollo de Software
III** (Licenciatura en Sistemas, Universidad John F. Kennedy), utilizado como
base para organizar las clases de este sitio.

- `32317 - Desarrollo de software III - 2023.doc`: documento original con
  fundamentos, objetivos, contenidos mínimos, programa analítico, metodología,
  evaluación y bibliografía.

El sitio reproduce los nueve temas del programa en las clases 1 a 9. La clase 0
funciona como presentación y reúne el programa, la metodología, la evaluación y
la bibliografía.

Los enlaces a eLibro que aparecen en el material requieren iniciar sesión con
las credenciales de la biblioteca virtual de la universidad.
