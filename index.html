Desarrollo de Software III

Material de clases sobre HTML y CSS: desde los orígenes del lenguaje de marcado hasta el diseño de interfaces responsivas, accesibles y mantenibles.

Programa 2023 · 64 horas · Régimen cuatrimestral · Código 32317

La materia

HTML es el lenguaje con el que se construye la web. Define la estructura y el contenido de una página —encabezados, párrafos, listas, enlaces, imágenes, tablas, formularios— y establece cómo se relacionan esas piezas entre sí. CSS, por su parte, se ocupa de la presentación: tipografía, color, espaciado, disposición y comportamiento en distintas pantallas.

El objetivo de la materia es comprender los conceptos fundamentales para construir una página o una aplicación web de forma eficaz, eligiendo la herramienta adecuada según el requerimiento y cuidando el rendimiento, la accesibilidad y la compatibilidad entre navegadores.

Al terminar la cursada vas a poder

  • Escribir documentos HTML válidos, semánticos y accesibles.
  • Estructurar contenido con la etiqueta adecuada para cada caso.
  • Construir enlaces, tablas, formularios y contenido embebido.
  • Aplicar estilos con CSS entendiendo la cascada, la herencia y la especificidad.
  • Diseñar interfaces adaptables a celulares, tablets y escritorio.
  • Leer y validar el código de cualquier sitio con las herramientas del navegador.

Cómo usar el sitio

El sitio está organizado como un recorrido: la clase 0 presenta la materia y cada clase siguiente desarrolla una unidad del programa. Podés avanzar con los enlaces anterior y siguiente que aparecen al final de cada página, o volver al índice desde el número 00 del encabezado.

Cada clase sigue la misma estructura:

  • Objetivos y desarrollo teórico, con definiciones y ejemplos.
  • Ejemplos interactivos: se muestran embebidos y también se pueden abrir en una pestaña aparte para leer y modificar el código.
  • Errores comunes, para reconocerlos antes de que aparezcan.
  • Actividad práctica, pensada para resolver en clase.
  • Resumen y bibliografía del tema.
Este sitio es parte del material

Está hecho con HTML y CSS, sin frameworks, sin JavaScript y sin paso de compilación. Podés ver el código fuente con Ctrl + U (o Cmd + U en macOS) y usar las herramientas de desarrollo con F12 para inspeccionar el DOM y los estilos.

Herramientas recomendadas

  • Un navegador actualizado (Firefox, Chrome, Edge o Safari).
  • Un editor de código con resaltado y autocompletado: VS Code, Sublime Text, Neovim o similares.
  • Las herramientas de desarrollo del navegador: pestañas Elements, Console y Network.
  • El validador del W3C para comprobar el HTML antes de entregar.

Metodología

La cursada es cuatrimestral, presencial y tiene una carga total de 64 horas reloj, distribuidas en quince encuentros de cuatro horas: dos horas teóricas y dos horas prácticas.

  • La teoría se desarrolla sobre la base de textos que se leen antes de la clase. Las primeras horas se destinan a consultas y a profundizar los conceptos principales.
  • La práctica consiste en ejercicios individuales y en un trabajo práctico grupal de aplicación.
  • Se requiere una asistencia mínima del 75 % y la aprobación de un examen final.

Evaluación

  • Dos evaluaciones parciales teórico-prácticas, ambas recuperables.
  • Carpeta de trabajos prácticos.
  • Trabajo práctico grupal.
  • Opinión formada por el docente a lo largo de la cursada.
